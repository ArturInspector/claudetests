# Socratic CLI

Simple command-line client for the Socratic learning API.

## Usage

- `socratic login` — authenticate and save token
- `socratic start "Topic"` — start a session
- `socratic list` — list sessions
- `socratic answer <id>` — submit an answer
- `socratic analyze <id>` — get session summary
- `socratic export <id>` — export to markdown or JSON
